# Identity decisions

Generated by MarketScan from `snapshots:sp500_history.csv`. Do not edit: regenerate with `marketscan --build-universe`.

A ticker is not an identity. A ticker dropped from the index and reassigned years
later to an unrelated company is **two securities sharing one string**, and treating
it as one welds the first company's price history to the second's -- manufacturing a
return that never existed, usually an enormous one.

The source here is ticker-keyed and cannot express identity, so it has to be inferred.
This file is every inference, including the ones that went the other way.

The threshold is a judgment call and not a derived constant, which is why this report
exists. **Over-splitting is the safe direction**: it costs history -- a strategy cannot
compute twelve-month momentum across a break -- and that is a visible, bounded loss.
Under-splitting fabricates a price series, which is invisible and poisons everything
downstream. When the rule is ambiguous, it splits.

Corrections go in `data/security_overrides.csv`, which is consulted before the
threshold.

## When CRSP arrives

PERMNO is a permanent security identifier that survives renames and is never reused --
exactly what this module infers. At that point `SecurityId` becomes PERMNO directly,
and this entire heuristic is **deleted rather than adapted**. The loader interface is
shaped so that deletion is the whole of the change, and this report stops being
generated because there is nothing left to decide.
